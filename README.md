# Artificial Intelligence Lab

Python lab work for the Artificial Intelligence course. Each notebook is self-contained and can be opened in Google Colab.

Repository: https://github.com/umar9991/Artificial-Intelligence-Lab

## Notebooks

1. [Python basics](https://colab.research.google.com/github/umar9991/Artificial-Intelligence-Lab/blob/main/notebooks/AI_Assignment_Python_Basics.ipynb) — input, decisions, match-case, loops, lists, and a matrix.
2. [Lab 1: Intelligent agents](https://colab.research.google.com/github/umar9991/Artificial-Intelligence-Lab/blob/main/notebooks/Lab1_Introduction_to_AI_Intelligent_Agents.ipynb) — PEAS, a reflex vacuum agent, a model-based agent, and a 3x3 grid agent.
3. [Lab 2: 8-puzzle](https://colab.research.google.com/github/umar9991/Artificial-Intelligence-Lab/blob/main/notebooks/Lab2_Problem_Formulation_8_Puzzle.ipynb) — problem formulation, breadth-first search, solvability, and missionaries and cannibals.

The same programs are in `programs/` so they can also be run locally:

```bash
python programs/ai_python_basics.py
python programs/intelligent_agents.py
python programs/eight_puzzle.py
```

In the Python basics notebook, set `LIVE_INPUT = True` to type your own answers.
